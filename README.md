# Zahlen-Ratespiel

Ein interaktives und unterhaltsames Zahlen-Ratespiel, bei dem Spieler versuchen müssen, 
eine zufällig generierte Zahl zwischen 1 und 100 zu erraten.

## Features

* **Zufallsgenerierung:** Generiert bei jedem neuen Spiel eine zufällige Zahl von 1 bis 100.

* **Echtzeit-Feedback:** Gibt Hinweise, ob die gesuchte Zahl höher oder niedriger ist.

* **Neustart-Funktion:** Ermöglicht ein schnelles Zurücksetzen des Spiels für eine neue Runde.

## Technologien

Dieses Projekt wurde mit Standard-Webtechnologien umgesetzt:
* **HTML5**
* **CSS3**
* **JavaScript**
